1. WHICH DUMMY DATA IS WHERE?

[A] HOMEPAGE HERO DATA

          2. UPVC Multi-Chamber Casement Windows (slug: "upvc-thermal-casement-windows")
          3. Architectural Aluminium Tilt & Turn Windows (slug: "architectural-aluminium-tilt-turn-windows")
          4. UPVC Smooth-Glide Sliding Windows (slug: "upvc-smooth-glide-sliding-windows")
        5 Doors:
          1. Heavy-Duty Aluminium Sliding Patio Doors (slug: "heavy-duty-aluminium-sliding-patio-doors")
          2. Oversized Architectural Pivot Entrance Doors (slug: "oversized-architectural-pivot-entrance-doors")
          3. UPVC Multi-Chamber Balcony Sliding Doors (slug: "upvc-multi-chamber-balcony-sliding-doors")

      - app/products/windows/[category]/page.tsx (Aluminium/UPVC/Sliding window filters)

2. ROUTING MAP (HOW EVERY URL ROUTES TO A PAGE)
--------------------------------------------------------------------------------

When a visitor visits a URL in their browser, Next.js App Router matches it
to a specific file in the `app/` folder. Here is the complete routing table:

URL Path                     File Path                             Type & Notes
--------------------------------------------------------------------------------
/                            app/page.tsx                          Static Page
                             - Shows HeroSection + Value Highlights + 3 Latest Blog Posts

/about                       app/about/page.tsx                    Static Page
                             - Company story, engineering values & consultation CTA

/contact                     app/contact/page.tsx                  Static + Client Form
                             - Contact channels with logos, Google Map & ContactForm

/products                    app/products/page.tsx                 Static Page
                             - Overview hub with Windows & Doors department cards

/products/windows            app/products/windows/page.tsx         Static Page
                             - All Windows collection + Material comparison table

/products/windows/aluminium  app/products/windows/[category]/page.tsx  Dynamic Sub-category
/products/windows/upvc       app/products/windows/[category]/page.tsx  (Pre-rendered at build
/products/windows/sliding    app/products/windows/[category]/page.tsx   via generateStaticParams)

/products/doors              app/products/doors/page.tsx           Static Page
                             - All Doors collection + Hardware engineering breakdown

/products/doors/aluminium    app/products/doors/[category]/page.tsx    Dynamic Sub-category
/products/doors/upvc         app/products/doors/[category]/page.tsx    (Pre-rendered at build
/products/doors/sliding      app/products/doors/[category]/page.tsx     via generateStaticParams)
/products/doors/glass        app/products/doors/[category]/page.tsx

/blog                        app/blog/page.tsx                     Static + Client List
                             - Featured story hero + BlogList with live search & filters

/blog/[slug]                 app/blog/[slug]/page.tsx              Dynamic Route
                             - Reads slug from URL (e.g. /blog/upvc-vs-aluminium-windows-comparison)
                             - Wrapped in React <Suspense> for Instant Navigation
                             - Pre-renders all 6 articles at build time

3. HOW TO CHANGE PAGES & DATA (STEP-BY-STEP)
--------------------------------------------------------------------------------

================================================================================
STEP 3.1: HOW TO CHANGE PHONE NUMBERS, WHATSAPP & EMAIL
================================================================================
There are 4 locations where contact info is referenced:

1. Contact Page Details & Google Maps:
   Open: app/contact/page.tsx
   Find lines 14-45 (the `CONTACT_CONFIG` object).
   Change:
     whatsapp: { display: "YOUR_PHONE", link: "https://wa.me/YOUR_PHONE?text=..." }
     phone: { display: "YOUR_PHONE", link: "tel:YOUR_PHONE" }
     email: { display: "YOUR_EMAIL", link: "mailto:YOUR_EMAIL" }

2. Contact Form WhatsApp forwarder:
   Open: components/ContactForm.tsx
   Find line 9:
     const WHATSAPP_PHONE = "YOUR_NUMBER_WITHOUT_PLUS"; // e.g. "919876543210"

3. Header Navbar "Get a Quote" Button:
   Open: components/Navbar.tsx
   Find line 35:
     const WHATSAPP_LINK = "https://wa.me/YOUR_PHONE_NUMBER";

4. Footer WhatsApp Button:
   Open: components/Footer.tsx
   Find line 3:
     const WHATSAPP_LINK = "https://wa.me/YOUR_PHONE_NUMBER";


================================================================================
STEP 3.2: HOW TO CHANGE THE GOOGLE MAP LOCATION
================================================================================
1. Open https://maps.google.com in your web browser.
2. Search your exact shop, factory, showroom, or office address.
3. Click the "Share" button on Google Maps.
4. Select the "Embed a map" tab.
5. In the HTML code provided by Google, copy ONLY the web address inside src="...".
   Example:
   src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!..."
6. Open: app/contact/page.tsx
7. Find `mapEmbedUrl` inside `CONTACT_CONFIG` (around line 38).
8. Paste your copied Google Maps URL as the new value.
9. Also update `addressLine1`, `addressLine2`, and `directionsUrl` in the same object.


================================================================================
STEP 3.3: HOW TO ADD OR EDIT A WINDOW OR DOOR PRODUCT
================================================================================
1. Open: data/products.ts
2. To EDIT an existing product:
   Find the product in the `productsData` array and modify its title, image,
   description, specs, or keyFeatures.
3. To ADD A NEW PRODUCT:
   Add a new object to `productsData` following this template:

   {
     id: "win-5",                                       // Unique ID
     slug: "casement-french-windows",                   // Unique URL slug
     title: "UPVC French Casement Windows",             // Product Name
     tagline: "Unobstructed double opening without central mullion",
     category: "windows",                               // "windows" or "doors"
     subCategory: "upvc",                               // "aluminium", "upvc", "sliding", or "glass"
     image: "https://res.cloudinary.com/demo/image/upload/sample.jpg", // Image URL
     description: "Detailed description of the window or door...",
     keyFeatures: [
       "Feature point 1",
       "Feature point 2",
       "Feature point 3"
     ],
     specs: {
       profileDepth: "60mm multi-chamber",
       glassOptions: "Double-glazed 24mm",
       soundInsulation: "Up to 36 dB",
       thermalPerformance: "U-value ≤ 1.4",
       hardware: "Multi-point locking shootbolts",
       warranty: "15-year warranty"
     },
     bestFor: "Balconies, master bedrooms, and heritage villas",
     guideSlug: "upvc-vs-aluminium-windows-comparison" // Optional blog guide link
   }

The new product will automatically appear on:
- /products (All Products)
- /products/windows (if category is "windows")
- /products/doors (if category is "doors")
- The respective sub-category page (e.g. /products/windows/upvc)


================================================================================
STEP 3.4: HOW TO ADD OR EDIT A BLOG ARTICLE
================================================================================
1. Open: data/blogs.ts
2. To EDIT an article:
   Find the article by its `slug` and update paragraphs, headings, or tips.
3. To ADD A NEW ARTICLE:
   Add a new object to the `dummyBlogPosts` array:

   {
     id: "7",
     slug: "how-to-choose-balcony-doors",
     title: "How to Choose the Best Balcony Doors for High-Rise Apartments",
     subtitle: "Wind resistance, water tightness, and child safety considerations.",
     excerpt: "A guide on selecting balcony doors that withstand monsoons and high winds...",
     category: "Doors", // "Windows", "Doors", "Energy & Insulation", "Design & Trends", or "Maintenance & Care"
     coverImage: "https://res.cloudinary.com/demo/image/upload/sample.jpg",
     author: {
       name: "Rajesh Sharma",
       role: "Senior Architectural Consultant",
       avatar: "https://res.cloudinary.com/demo/image/upload/samples/people/smiling-man.jpg"
     },
     publishedAt: "2026-10-27",
     readingTime: "5 min read",
     featured: false, // Set to true to make it the top hero banner on /blog
     tags: ["Balcony Doors", "Sliding Doors", "Wind Resistance"],
     sections: [
       {
         heading: "1. Why High-Rise Balconies Demand Heavy-Duty Doors",
         paragraphs: [
           "At elevations above the 10th floor, wind pressures increase exponentially...",
           "Standard sliding doors without wind load reinforcements can rattle..."
         ],
         bulletPoints: [
           "Look for heavy-duty interlocks with structural steel stiffeners.",
           "Ensure bottom tracks have calibrated drainage weep holes."
         ],
         callout: {
           type: "tip", // "tip" or "important"
           title: "Safety First",
           text: "Always specify toughened tempered safety glass (minimum 8mm-10mm) for balcony doors."
         }
       }
     ]
   }

Next.js will automatically:
- Render it in the `/blog` index grid.
- Enable live category filtering and search for it.
- Statically pre-render the full article at `/blog/how-to-choose-balcony-doors`.


================================================================================
STEP 3.5: HOW TO USE YOUR OWN CLOUDINARY ACCOUNT
================================================================================
1. By default, the site uses Cloudinary's demo cloud name ("demo").
2. To use your personal Cloudinary cloud:
   Create a file named `.env.local` in the project root:
   ```env
   NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_own_cloud_name
   ```
3. When you upload photos to Cloudinary, you can use:
   - Either the full URL:
     `https://res.cloudinary.com/your_cloud/image/upload/v12345/doors/slider.jpg`
   - Or just the Cloudinary Public ID:
     `doors/slider`
   The helper in `lib/cloudinary.ts` will automatically format and optimize it.


================================================================================
STEP 3.6: HOW TO CHANGE NAVIGATION MENUS & DROPDOWNS
================================================================================
1. Open: components/Navbar.tsx
2. Find `navLinks` (lines 7-33):
   - You can add, remove, or rename menu items.
   - For links with dropdowns, edit the `submenu` array:
     ```ts
     {
       name: "Windows",
       href: "/products/windows",
       submenu: [
         { name: "All Windows", href: "/products/windows" },
         { name: "Aluminium Windows", href: "/products/windows/aluminium" },
         { name: "UPVC Windows", href: "/products/windows/upvc" },
         { name: "Sliding Windows", href: "/products/windows/sliding" },
       ]
     }
     ```

   - Teal Light: #14A693

   - Slate Gray: #6B7280 (descriptions, dates, subheads)

If you ever wish to modify theme colors globally, change the CSS variables
inside `@theme inline` in `app/globals.css`.
